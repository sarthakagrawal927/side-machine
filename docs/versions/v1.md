# v1.0.0 — LAN command suite

v1 is the first working Side Machine release. It assumes the controller can
reach `Assistants-MacBook-Pro.local` on the same LAN.

## Commands

```bash
side-chick
side-chick alive
side-chick status
side-chick speed
side-chick watch 5
side-chick herdr
side-chick setup-key
side-chick version
```

## Authentication

`side-chick setup-key` creates a dedicated Ed25519 key on the controller and
asks for the worker password once to authorize its public key. The password is
never stored. The helper uses that key automatically on later connections.

## Persistence

Herdr owns persistent agent panes. launchd keeps Herdr and caffeinate running.
tmux remains installed solely as a direct recovery fallback.

## Network reporting

`side-chick status` shows the instantaneous Wi-Fi PHY link rate and signal.
`side-chick speed` runs Apple's `networkQuality` for real upload/download
throughput and latency.
